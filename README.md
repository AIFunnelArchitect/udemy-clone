# Udemy Clone
Cloned and Push using Git to GitHub

This project is a **Udemy website clone** created using HTML and CSS as part of my web development learning journey.

While building this project, I practiced creating website layouts, styling elements with CSS, organizing files, and using **Git and GitHub** to manage and store my project.

### What I Learned

* Creating a website using HTML
* Styling and designing pages using CSS
* Structuring a project with multiple files
* Using Git for version control
* Creating and managing a GitHub repository
* Cloning and pushing a project to GitHub

This project is built for **learning and practice purposes** and is not affiliated with Udemy.
